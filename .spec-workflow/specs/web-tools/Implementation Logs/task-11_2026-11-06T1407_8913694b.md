# Implementation Log: Task 11

**Summary:** Config and Engine wiring for web_fetch (plus the browser registration that task 19 needs). TantalumProperties gained component Web(blockPrivateNetwork, Fetch(enabled), Browser(enabled, maxOpen, idleClose, sandbox)). Browser rejects maxOpen < 1 and a non-positive idleClose, so binding fails at startup. Added Web.defaults()/any() and webSettings(), which falls back to defaults when the section is missing. application.properties has the design's six lines and comments. Engine: one ToolImages shared by LocalTool, MCP (McpRegistry(mcpSettings, toolImages), deferred from ebcab67) and Browsers. AddressRules is always created (rules only, no network). Egress.start(rules, UpstreamProxy.fromEnvironment(System::getenv)) runs only when fetch or browser is enabled. web_fetch is registered when fetch is enabled. WebAccess (built from the admin flags) always goes into PluginGate's group list with LocalWorkspace, so the plugin page still shows the group when both items are off. fixedNote = MCP note + WebAccess.NOTE when any web item is on. close() runs "close browsers" and then "close egress" right after handlers stop and local links close. Failures midway through the constructor close the egress and browsers. New public accessors: addressRules(), webAccess(), and egress()/browsers() as Optional for diagnostics and tests. TantalumApplication: the engine bean sets ownPort from server.port when it is > 0, an ApplicationListener<WebServerInitializedEvent> sets the actual port, and the `browser` command branch (deferred from ebcab67) calls BrowserCommand.run. KernelFactory.safety registers WebFetchTool(null) when fetch is enabled so the `check` command replays parallel web_fetch calls the same way. Deviation: the Engine-level tests live in a new WebToolsWiringTest instead of being split across ContextHandlerTest and ShutdownOrderTest (ContextHandler only receives fixedNote, so the composition can only be tested through the server). Tests: TantalumPropertiesTest (defaults equal Web.defaults(), overrides, max-open=0 gives BindException naming max-open, missing section gives defaults); WebToolsWiringTest on a real server with a random port (web_fetch and 11 browser_* registered, no browser started; the system prompt contains the "## Web content" note; web_fetch to the server's own random port is blocked with "Blocked: 127.0.0.1:<port> is the Tantalum server itself." with block-private-network=false (4.4); fetch.enabled=false leaves no web_fetch and admin web-fetch=false; both off means no egress, no browsers, no note (5.3); after shutdown the egress port refuses connections (2.8)).
