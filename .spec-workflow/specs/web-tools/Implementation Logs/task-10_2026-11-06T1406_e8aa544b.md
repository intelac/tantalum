# Implementation Log: Task 10

**Summary:** Generalized the local-workspace switch group into access/ToolGroup (kind, switches with the master first, owns, enabled, source) and added access/WebAccess (MASTER web, FETCH web-fetch, BROWSER browser, SWITCHES, SOURCE web, NOTE = the design's "## Web content" text; owns by tool.server(); enabled = master x sub switch; switches(user), admin() {web-fetch, browser}, blockPrivateNetwork()). LocalAccess deleted (the deletion went into the parent's commit 7811e59 by accident; the working tree is the same): MASTER, SWITCHES and SOURCE "local" now live in LocalWorkspace, which implements ToolGroup. PluginSwitches.Kind gained WEB, and the table is unchanged. PluginGate takes List<ToolGroup> (two groups may not share a kind). toolEnabled, overview and set(TOOL) skip grouped tools; set(LOCAL|WEB) accepts only that group's switch names, otherwise UnknownPlugin, and a switch the admin turned off can still be saved. New PluginGate.source(Tool) returns the group source, else builtin or mcp:<server>. ContextHandler.sources() calls it. WebFetchTool.server() is WebAccess.FETCH and BrowserTool.SERVER is WebAccess.BROWSER (placeholders replaced). Deferred wiring from ebcab67 done here too: LocalTool takes ToolImages (store-image loop replaced by ToolImages.output; the error wording is now "Cannot store image <file name>", and no test asserted the old text). The transitional McpRegistry(McpSettings) and McpRegistry(settings, policy) constructors are deleted, along with McpTool's images==null branch. Tests: WebAccessTest (full table of admin x master x sub for fetch and browser through PluginGate, builtins unaffected; defaults on and per user; web tools not in builtins, no per-tool switch, source web; unknown WEB names refused, no LOCAL group means LOCAL refused; an MCP server named browser is not the browser), ContextHandlerTest source map now includes web_fetch -> web, PluginGateTest and LocalWorkspaceTest only changed constructor arguments (assertions unchanged), and new ArchitectureTest rule accessKnowsNoWebTools.
