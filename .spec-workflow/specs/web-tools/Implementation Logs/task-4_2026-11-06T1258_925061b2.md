# Implementation Log: Task 4

**Summary:** Follow-up: CONNECT tunnels now have a total lifetime cap Egress.TUNNEL_LIFETIME = 30 minutes regardless of traffic (a busy WebSocket/long poll could otherwise hold one of the 512 slots forever; the per-user browser closes after 10 min idle anyway). Implemented as a per-tunnel virtual watchdog thread that closes both sockets at the deadline (works even if both directions are stuck in writes) and is interrupted when the tunnel ends; the 5-minute idle rule is unchanged. Package-private Egress.start(rules, upstream, lifetime) for tests. Also added Egress.rules() so the browser can pre-check a URL's host for a clear message. Test: EgressTest.aBusyTunnelIsClosedWhenItsLifetimeIsOver (a peer writing every 50 ms through a 1 s tunnel is cut after 0.9-5 s; the default is pinned at 30 min).
