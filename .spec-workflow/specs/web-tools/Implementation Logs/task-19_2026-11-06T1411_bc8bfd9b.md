**Summary:** Browser wiring into Engine. When tantalum.web.browser.enabled is set, Engine builds Browsers(Settings(maxOpen, idleClose, sandbox), egress, the shared ToolImages, clock, new BrowserDriver(dataDir)) and registers BrowserTools.all(browsers).
