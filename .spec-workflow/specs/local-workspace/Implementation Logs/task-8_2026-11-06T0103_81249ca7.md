# Implementation Log: Task 8

**Summary:** Server side of the connection. LocalEndpoint: Jakarta WebSocket endpoint /api/local/connect registered on Tomcat's ServerContainer from a ServletContextInitializer bean in TantalumApplication that adds a ServletContextListener (Spring's initializer runs before Tomcat's WsSci, so the container only exists in contextInitialized); no new dependency. Handshake Configurator reads Authorization: Bearer, stores only the LocalTokens.Verdict + nanoTime in per-session user properties; onOpen closes 4401 invalid / 4403 expired|revoked; first message must be hello within Timing.hello (5 s) else 1008; protocol mismatch 4400; non-hello first 1008; text buffer 16 MB; sends serialized per session. LocalLinks: one Link per principal; attach(principal, expiresAt, verifiedAt, hello, peer) -> Optional<Link> (refused if revoke happened after the handshake), old link gets bye replaced + 4409, expiry timer sends bye expired + 4403, revoke(principal) revokes tokens + bye revoked + 4403, close() sends bye shutdown + 1001; heartbeat ping every Timing.ping (15 s), close 1001 after Timing.silence (45 s) without pong; call(principal, session, tool, args, timeout) with fair 4-permit semaphore per link (queue time counts), cancel on timeout/interrupt, pending calls complete with "The computer disconnected. Whether this operation finished is unknown." on drop, "The local workspace is not connected." without a link; agents(principal) sends context and waits Timing.agents (2 s); status(principal). Wrong-direction messages close 1002. Engine opens LocalTokens + LocalLinks (Timing.DEFAULT), exposes localLinks(), closes links after handlers drain and tokens with switches. SecurityConfig permitAll for /api/local/connect only.
